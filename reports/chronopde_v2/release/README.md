# ChronoPDE V2 release evidence

This directory contains lightweight release metadata only. Large datasets,
checkpoint archives, recovery bundles and Kaggle outputs remain private and are
not tracked by Git.

`artifact_manifest.json` records each frozen artifact's role, expected hash,
storage location and local verification state. The local archive root is
`ChronoPDE_V2_Archive/` beside the repository; it is intentionally ignored and
must not be published with the source release.

The scientific decision remains defined by the Phase 6 protocol and decision
report. The storage manifest cannot authorize or change a scientific claim.
